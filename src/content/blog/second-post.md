## 为什么选择 Astro + Cloudflare Pages？

**Astro** 是一个现代静态网站生成器，默认输出零 JavaScript，非常适合内容驱动的个人网站。

**Cloudflare Pages** 提供免费、快速的静态网站托管，全球 CDN 加速。

### 步骤概览

1. 初始化 Astro 项目
2. 编写页面和组件
3. 推送至 GitHub
4. 在 Cloudflare Pages 中连接仓库
5. 自动构建与部署

### 优势

- 🚀 全球 CDN 加速
- 💰 免费托管
- 🔄 Git 推送自动部署
- 🔒 免费 SSL 证书

```bash
# 本地开发
npm run dev

# 构建生产版本
npm run build
```

就是这么简单！
